# 云智实训助手 · 私有化知识库

> 本知识库为「云智实训助手」的私有化实训知识库，采用 RAG（检索增强生成）技术检索。
> 数据绝对本地化，仅供高职云计算实训课堂教学使用。

## 知识库现状（v2.0）

| 数据集 | 文件 | 条目数 | 覆盖范围 |
|--------|------|--------|----------|
| 智能问答 | `qa_data.json` | **47** 条 | 云计算基础/计算/网络/存储/数据库/容器/安全/运维/面试 |
| 任务引导 | `task_data.json` | **12** 个 | VPC规划、MySQL部署、Nginx+HTTPS、Docker、Compose、SLB高可用、OSS+CDN、监控告警、备份恢复、安全组、弹性伸缩等 |
| 排错诊断 | `trouble_data.json` | **30** 条 | SSH/网络/服务/磁盘/内存/DNS/K8s/Docker/数据库/证书 等 25+ 常见故障 |

## 检索说明

- **意图识别**：收到输入后先判断属于【知识问答】【任务引导】【排错诊断】【报告辅助】中的哪一类
- **关键词提取**：提取核心技术词（如报错代码、云服务名称、配置参数）用于精准检索
- **引用溯源**：在回答末尾标注参考来源，增强可信度

## 教师扩充指南

直接编辑 `qa_data.json` / `task_data.json` / `trouble_data.json` 三个文件即可。**编辑后无需重启后端，刷新网页即生效**。

**QA 库条目模板：**
```json
{
  "id": "唯一英文标识",
  "keywords": ["关键词1", "关键词2"],
  "answer": "支持 HTML：<strong>加粗</strong><br>换行<br><code>命令</code>",
  "source": "《参考教材名》第几章"
}
```

**任务库条目模板：**
```json
{
  "id": "唯一英文标识",
  "name": "任务名称",
  "keywords": ["关键词1"],
  "goal": "学习目标",
  "env": "环境要求",
  "steps": [
    {"title": "步骤标题", "detail": "操作指令", "expect": "预期结果", "tip": "小贴士"}

}
```
