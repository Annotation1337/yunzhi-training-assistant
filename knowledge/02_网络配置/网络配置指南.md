# 网络配置（VPC / 子网 / 安全组）

## 1. VPC（虚拟私有网络）

VPC 是在云上划分出的逻辑隔离的私有网络空间，每个 VPC 拥有独立的 IP 网段（CIDR）。

**示例**：`10.0.0.0/16` 表示约 6.5 万个 IP 地址。

## 2. 子网（Subnet）

子网是对 VPC 网段的进一步细分，用于把不同用途的资源划分到不同网段。

**关键原则**：
> 子网网段必须是 VPC CIDR 范围的子集。

例如：
- VPC：`10.0.0.0/16`（约 6.5 万 IP）
- 子网：`10.0.1.0/24`（256 个 IP），属于 VPC 范围

## 3. 安全组（Security Group）

安全组是虚拟防火墙规则，控制云主机的入站和出站流量。

**默认规则**：拒绝所有入站流量，仅放通明确允许的端口。

**常用端口**：
| 端口 | 协议 | 用途 |
|------|------|------|
| 22 | TCP | SSH 远程登录 |
| 80 | TCP | HTTP 网站 |
| 443 | TCP | HTTPS 网站 |
| 3306 | TCP | MySQL 数据库 |

## 4. CIDR 网段规划

| CIDR | 可用 IP 数 | 适用场景 |
|------|-----------|---------|
| /16 | 65536 | 大型 VPC |
| /24 | 256 | 常规子网 |
| /28 | 16 | 小型测试网段 |

> 规划时需预留足够 IP，避免子网可用 IP 不足。

## 5. 常见配置流程

1. 选择 VPC（确认地域与可用区）
2. 选择子网（确认 CIDR 与可用 IP）
3. 选择安全组（放通必要端口）
4. 设置带宽（按业务峰值预估）
5. 高级配置（弹性 IP、IPv6 等）
