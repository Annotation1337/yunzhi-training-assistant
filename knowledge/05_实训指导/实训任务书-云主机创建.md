# 实训任务书 · 云主机创建与网络配置

## 一、实训目的

1. 掌握云主机（云服务器）的完整创建流程
2. 理解 VPC、子网、安全组三个核心网络概念及关系
3. 学会根据业务需求合理规划网络参数
4. 培养规范操作、记录配置、排查问题的工程化思维

## 二、实训环境

| 项目 | 配置 |
|------|------|
| 云平台 | 通用云平台控制台 |
| 地域/可用区 | 华北1 / 可用区 A |
| 操作系统 | Ubuntu 22.04 |

## 三、实训步骤

### 步骤一：进入创建页面
登录云平台控制台 → 计算 → 云主机 → 创建实例

### 步骤二：基础配置
- 选择地域、可用区
- 选择实例规格（如 2核4G）

### 步骤三：镜像选择
- 选择 Ubuntu 22.04 LTS 镜像

### 步骤四：网络配置（重点）
- VPC：`vpc-prod-01`（10.0.0.0/16）
- 子网：`subnet-web-01`（10.0.1.0/24）
- 安全组：放通 22/80/443 端口
- 公网带宽：按需设置

### 步骤五：系统配置
- 设置登录密码、主机名

### 步骤六：确认下单
核对配置，完成创建

## 四、验收标准

- [ ] 云主机创建成功
- [ ] 能通过 SSH 远程登录
- [ ] 安全组端口配置正确
- [ ] 能正确描述 VPC、子网、安全组关系

## 五、思考题

1. 为什么子网网段必须在 VPC CIDR 范围内？
2. 安全组默认是放通还是拒绝流量？为什么？
3. 如何为不同用途的资源（Web 层、数据库层）规划子网？
