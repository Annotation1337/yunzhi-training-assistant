# 服务部署指南

## 1. 云主机（ECS/虚拟机实例）创建

云主机创建一般包含以下步骤：

1. **基础配置**：选择地域、可用区、实例规格
2. **镜像选择**：选择操作系统镜像（如 CentOS、Ubuntu、Windows）
3. **网络配置**：选择 VPC、子网、安全组
4. **系统配置**：设置登录密码、主机名
5. **确认下单**：核对配置，完成创建

## 2. Web 服务部署（以 nginx 为例）

### 安装 nginx
```bash
sudo apt update
sudo apt install -y nginx
```

### 启动服务
```bash
sudo systemctl start nginx
sudo systemctl enable nginx   # 开机自启
```

### 查看状态
```bash
sudo systemctl status nginx
```

### 验证
```bash
curl http://localhost
```

## 3. 数据库服务部署（以 MySQL 为例）

```bash
sudo apt install -y mysql-server
sudo systemctl start mysql
sudo mysql_secure_installation  # 安全初始化
```

## 4. 容器服务部署（Docker）

```bash
# 安装 Docker
curl -fsSL https://get.docker.com | sh

# 运行容器
docker run -d -p 80:80 --name web nginx

# 查看容器
docker ps
```

## 5. 部署注意事项

- 安全组需放通对应端口（22/80/443）
- 服务需配置开机自启（`systemctl enable`）
- 防火墙（firewalld/iptables）需放行端口
- 公网 IP 需正确绑定才能外网访问
