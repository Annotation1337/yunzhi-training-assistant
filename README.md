# 云智实训助手 · 本地部署说明（Windows 版）

> 高职云计算实训课堂 AI 助教系统，本地化部署，数据绝不上传外发。

---

## 一、为什么之前 localhost 打不开？

之前的服务运行在**云端沙箱（Linux）**里，不是您的 Windows 本机。
您需要把文件**下载到自己的电脑上**，在自己电脑里运行，才能访问 `localhost:5000`。

## 二、目录结构

根目录只保留**一个入口脚本**，其余工具脚本全部收纳在 `tools/` 中：

```
yunzhi-project/
├── 一键运行.bat          # ⭐⭐ 唯一入口！普通用户只需要双击这一个文件
├── app.py                # Flask 后端入口
├── qa_engine.py          # 问答引擎（知识库优先 → RAG → 联网兜底）
├── llm_engine.py         # 本地大模型引擎（Ollama + RAG + 联网总结）
├── web_search_engine.py  # 联网搜索兜底引擎（必应/百度/搜狗五引擎择优）
├── report_engine.py      # 报告生成引擎（一键生成实训报告框架）
├── task_engine.py        # 任务引导引擎（分步推送 + 进度跟踪）
├── diagnose_engine.py    # 排错诊断引擎（报错特征匹配 + 截图OCR）
├── speech_engine.py      # 语音识别引擎（Vosk 本地离线 ASR，普通话）

│   └── vosk/             # 中文语音识别模型（约 66MB，由安装脚本下载）

├── requirements.txt      # Python 依赖（flask、beautifulsoup4 等）
├── index.html            # 网页前端（含聊天界面）
├── 云智实训助手.html      # 单文件静态版（无需后端，可直接双击）
├── css/  js/  images/    # 前端样式 / 交互脚本 / 图片
├── knowledge/            # 私有化知识库
│   ├── qa_data.json      # 问答对数据（47条）

    ├── 一键安装.bat        # 安装向导（必选自动 + 可选菜单，支持 /auto）
    ├── 启动.bat            # 仅启动（检查依赖 + 打开网页）
    ├── 安装Python.bat      # 单独安装 Python 3.11
    ├── 安装Ollama.bat      # 单独安装 Ollama

    ├── 安装画图依赖.bat    # 补装 matplotlib + PyTorch + diffusers（画图用）
    ├── 下载StableDiffusion.bat  # 单独下载 SD 插画模型（约 4GB，国内源优先）
    ├── 安装模型_xxx.bat    # 单独下载模型，共 6 个
```

## 三、Windows 运行步骤（普通用户：只认一键运行.bat）

### 第 1 步：解压文件

把 `yunzhi-project.zip` 解压到任意位置，例如：

```
D:\yunzhi-project\
```

### 第 2 步：双击 `一键运行.bat`，完成

不需要关心别的。它会**自动检测环境 → 缺什么补什么 → 询问是否启动**：

| 步骤 | 类型 | 检测内容 | 缺失时 |
|------|------|----------|--------|
| 1. Python | 必选 | 版本 + 安装位置（`where python`） | 自动安装（winget → 华为云镜像 → 官网），装完刷新 PATH 继续 |
| 2. 后端依赖 | 必选 | flask / bs4 导入测试 | 自动 pip 安装（清华镜像源） |
| 3. Ollama | 可选 | 安装位置（`where ollama`）+ 版本 + 服务是否在线 | 弹出说明（是什么/不装会怎样/怎么运行），询问 `[1=安装 / 2=跳过并记住]` |
| 4. 大模型 | 可选 | 已装模型列表 + 存储目录 `%USERPROFILE%\.ollama\models` | 显示 6 选 1 菜单（按内存选），回车默认跳过并记住 |
| 5. SD 画图 | 可选 | PyTorch / diffusers + 模型文件完整性 | 提示「一键补装/下载」，回车默认跳过并记住 |
| 6. 语音识别 | 可选 | vosk 库 + `models\vosk\am\final.mdl` | 询问 `[1=安装(推荐) / 2=跳过并记住]`，**回车默认安装**（仅 45MB） |
| 7. 汇总+启动 | — | 打印「当前可用功能」清单 | 回车立即启动，输入 2 退出 |

第 3/4/6 步的询问只出现一次：选择「跳过」会在根目录生成隐藏标记文件（`.yz_skip_ollama` / `.yz_skip_model` / `.yz_skip_sd` / `.yz_skip_asr`），下次不再询问；想重新开启询问，删除对应文件即可。

第 3/4 步会**详细解释每个可选组件**：作用、不装会怎样、存放位置、以后想装怎么操作——学生不用查资料就能做决定。

**不装可选组件也能用**：仅 Python + 依赖即可获得知识库问答 + 联网搜索兜底 + 任务引导 + 排错诊断 + 报告生成全部核心功能。

### 全自动模式（竞赛部署 / 机房批量装机）

命令行执行 `一键运行.bat /auto`：必选组件缺失自动安装，可选项自动装 **Ollama + qwen2.5:3b + 语音识别组件**（SD 模型 4.2GB 仍默认跳过），装齐后**直接启动**，全程无需按键。适合机房批量装机。

### tools/ 里的脚本是干什么的？

日常使用**不需要**它们。仅在这些情况才进 `tools/`：

| 场景 | 用哪个 |
|------|--------|
| 电脑已装好环境，只想启动不检测 | `tools\启动.bat` |
| 想单独补装 Ollama / 某个模型 | `tools\一键安装.bat` 或 `tools\安装Ollama.bat`、`tools\安装模型_xxx.bat` |
| 想单独装 Python | `tools\安装Python.bat` |
| 想开「麦克风语音输入」 | `tools\安装语音识别.bat`（约 45MB，一次性） |

> `tools/` 下的脚本运行时会自动回到项目根目录工作，放在哪个文件夹双击都可以。

## 四、常见问题

### Q1：双击 一键运行.bat 闪一下就没了？
可能是 Python 没装或没勾选 PATH。请**双击 `tools\安装Python.bat`** 装好 Python，再重新双击根目录 `一键运行.bat`。

### Q2：提示"未检测到 Python"或"Python 安装失败"？
双击 `tools\安装Python.bat` 安装 Python（它会依次尝试 winget / 华为云镜像 / 官网）。若仍失败，通常是网络不通或杀毒软件拦截了安装包，请手动到 https://www.python.org/downloads/ 下载安装，记得勾选 `Add Python to PATH`，然后重新双击根目录 `一键运行.bat`。

### Q3：服务启动了但浏览器没自动打开？
属于少数系统环境差异。手动在浏览器地址栏输入 `http://localhost:5000` 即可访问（服务已在后台运行）。

### Q4：端口 5000 被占用？
修改 `app.py` 最后一行的 `port=5000` 为 `port=5001`，然后访问 `http://localhost:5001`。

### Q4：只是想快速看页面，不想装 Python？
双击 **`云智实训助手.html`**（单文件版），可以直接看到页面排版，报告生成功能也可用（纯前端版）；但**智能问答功能不可用**（需要后端）。

### Q5：手机上能访问吗？
可以。确保手机和电脑连同一个 WiFi，先查电脑 IP（cmd 输入 `ipconfig`），把 `app.py` 的 `host="127.0.0.1"` 改成 `host="0.0.0.0"`，然后手机访问 `http://电脑IP:5000`。

### Q6：画图页报错 `No module named 'matplotlib'` 或 `No module named 'torch'`？
这表示缺画图依赖，**不影响其他功能**（问答/任务/排错/报告照常用）。修复方式二选一：

- **一键补装（推荐）**：双击 `tools\安装画图依赖.bat`，它会自动装 `matplotlib`（约 40MB）+ `torch/diffusers`（约 2-3GB，有无独显自动适配），完成后重新双击根目录 `一键运行.bat`。
- **手动命令**：
  ```bash
  python -m pip install matplotlib -i https://pypi.tuna.tsinghua.edu.cn/simple
  python -m pip install torch diffusers transformers accelerate safetensors -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

> 注意区分两种报错：
> - `matplotlib` 缺失 → **拓扑/架构图也无法生成**（整个画图页不可用）
> - 仅 `torch/diffusers` 缺失 → **拓扑图正常，仅「插画」不可用**

### Q7：装了模型但启动日志显示"模型 qwen2.5:3b 未安装"？
系统默认首选 `qwen2.5:3b`，但**已自动支持切换到本机已装的任意模型**（无需手动配置）。启动日志里的"使用模型 XXX"就是实际生效的模型名。若要强制指定，启动前设置环境变量：`set OLLAMA_MODEL=你的模型名`。

### Q8：出图用 CPU 太慢（30-60 秒）？
Stable Diffusion 在无 NVIDIA 独显的机器上走 CPU 推理，速度较慢属正常。缓解方式：
- 插画类 prompt 尽量简单（如"画一只猫"），避免复杂场景描述
- 拓扑/架构图走 matplotlib，**始终 1-3 秒出图**，是首选
- 有 NVIDIA 独显的机器，运行 `tools\安装画图依赖.bat` 会自动装 GPU 版 PyTorch，速度提升 10 倍以上

### Q9：为什么大模型装在 `C:\Users\你\.ollama\models`，不放在项目的 `models\` 里？

**这是正常的，不是装错位置。** 项目里有两个同名但完全不同的 `models` 目录：

| 目录 | 存什么 | 谁管理 | 能否改 |
|---|---|---|---|
| `C:\Users\你\.ollama\models` | **Ollama 大模型**（qwen2.5 / deepseek 等） | Ollama 官方，路径写死 | ❌ 不能改，改了 Ollama 找不到模型 |
| `yunzhi-project\models\sd\` | **Stable Diffusion 绘图模型**（约 4GB） | 本项目自己管理 | ✅ 由项目代码控制 |
| `yunzhi-project\models\vosk\` | **语音识别中文模型**（约 66MB） | 本项目自己管理 | ✅ 由项目代码控制 |

> 简单记：**Ollama 的模型归 Ollama 管，SD / 语音模型归项目管**，两者互不相干。强行把 Ollama 模型挪到项目目录会导致 Ollama 报"模型不存在"。

大模型占空间想释放：`ollama rm 模型名`（在 CMD 里执行）即可删除。

### Q10：麦克风按钮点了没反应 / 提示"语音输入未就绪"？

按下面顺序排查：

| 现象 | 原因 | 解决 |
|------|------|------|
| 输入框下方黄字提示「语音输入未就绪」 | 没装语音组件 | 双击 `tools\安装语音识别.bat`，或重跑 `一键运行.bat` 在第 6 步选安装 |
| 点了按钮提示「无法使用麦克风」 | 浏览器麦克风权限被拒 | 点地址栏左侧的 🔒 图标 → 网站设置 → 麦克风 → 允许，刷新页面 |
| 提示「没有检测到麦克风设备」 | 没插话筒 / 设备管理器禁用 | 插好耳麦后刷新页面重试 |
| 录音结束提示「没能听清」 | 环境噪声大或说话太小声 | 靠近麦克风、用普通话、语速稍慢 |
| 用的是 IE / 老版浏览器 | 不支持 Web Audio | 换 **Edge 或 Chrome** 打开 |

> 语音功能**完全可选**：装不上也不影响键盘输入，智能问答的其余功能一切正常。

### Q11：AI 回答的「朗读」按钮没声音？

| 排查 | 说明 |
|------|------|
| 系统音量 | 检查一下是否静音、音量是否为 0 |
| 浏览器 | IE 不支持，请用 **Edge / Chrome** |
| Windows 发音引擎 | 某些精简版系统删掉了中文发音人。设置 → 时间和语言 → 语音 → 管理语音 → 添加「中文（中国）」语音包 |
| 点了没反应 | 部分浏览器首次朗读需要一次真实点击，多点一次试试 |

朗读用的是**操作系统自带发音引擎**，不联网、不需要额外安装任何东西。

## 五之二、语音交互：说话提问 + 朗读回答

智能问答页提供两个语音功能，**一进一出的完整闭环**：

| 功能 | 位置 | 技术 | 联网？ |
|------|------|------|--------|
| **语音输入**（普通话 → 文字） | 输入框右侧「🎤 语音」按钮 | Vosk 离线识别（本地模型） | ❌ 全程离线 |
| **语音朗读**（AI 回答 → 语音） | 每条 AI 回答下方「🔊 朗读」按钮 | 浏览器内置语音合成 | ❌ 系统发音 |

### 学生怎么用

**语音输入**
1. 进入「智能问答」页，点输入框右侧的 **🎤 语音** 按钮
2. 浏览器弹出麦克风授权 → 点「允许」（只需授权一次）
3. 按钮变红并开始计时，用**普通话**说出问题
4. 再点一次 **⏹ 结束**，等待 1-2 秒，识别文字自动填入输入框
5. 可直接在输入框里修改后点「发送」

最长录音 60 秒，到时自动结束；中途点「结束」也可以。

**语音朗读**
每条 AI 回答左下方都有 **🔊 朗读** 按钮，点一下开始朗读，再点一下（此时显示 **⏹ 停止**）立即停止。切换页面或发送新问题时会自动停止。

> 朗读前会把 Markdown 语法清洗成纯文本，不会把 `**`、`#`、图片链接念出来；代码块会提示「请看屏幕上的代码块」。

**方式一（推荐）：双击根目录 `一键运行.bat` 时顺手装上**
运行到第 6 步会自动检测并询问：

```

  装了之后      : 学生不用打字,说完自动转成文字填进输入框
  不装会怎样    : 不影响任何功能,学生仍可键盘输入问题
  大小          : 约 45MB [库 3MB + 中文模型 42MB],约 1-3 分钟
  数据说明      : 纯本地离线识别,音频不上传任何外部服务器
```

**方式二：事后单独补装**

双击 **`tools\安装语音识别.bat`**，自动完成两件事：

| 内容 | 大小 | 来源 |
|------|------|------|
| vosk 库 | 约 3 MB | 清华 PyPI 镜像 |
| 中文模型 `vosk-model-small-cn-0.22` | 约 42 MB | alphacephei 官方 → hf-mirror 国内镜像 → huggingface 兜底 |

若此时云智正在运行，装完**重启云智**（关掉黑窗口重双击 `一键运行.bat`）即可生效；未运行时，下次启动自动生效。

> 未安装时一键运行会显示「语音识别：未启用」，**键盘输入完全不受影响**。

### 数据本地化说明（重要）

| 环节 | 数据去向 |
|------|----------|
| 录音采集 | 浏览器本地，通过 Web Audio 直接采 PCM |
| 音频传输 | 仅发往本机 `http://localhost:5000/api/speech/recognize`，不出机房 |
| 识别推理 | 本地 Vosk 模型，纯 CPU 推理 |
| 音频留存 | 写入系统临时目录，**识别完成立即删除**，不落盘不归档 |
| 语音朗读 | 操作系统自带发音引擎，不涉及网络 |

**刻意未使用**浏览器自带的 `webkitSpeechRecognition`：Chrome 的实现会把音频上传到境外服务器识别，违背「数据绝对本地化」红线。

### 已知限制与教学建议

| 现象 | 原因 | 建议 |
|------|------|------|
| 英文缩写识别成音译汉字（如 VPC → "维普西"、Docker → "道克"） | small 模型的中文词表有限 | 识别后在输入框手动改成 `VPC`、`Docker`，正好练术语拼写 |
| 环境嘈杂时识别率下降 | 麦克风采集到噪声 | 用耳麦，或让学生键盘输入 |
| 首次识别慢 5-10 秒 | 首次需加载 66MB 模型到内存 | 属正常现象，之后每次 1-2 秒 |

**为什么不给模型加热词表？** 实测 Vosk 的 grammar（词表）模式是**封闭语法**，只能识别词表内的词。加入云计算术语后，原本能正确识别的整句被严重带偏（例："怎么创建云主机和配置安全组" → "是什么迁移主从磁盘日志进程主从"）。因此保持**开放识别模式**，靠学生手动补正术语。

如需更高术语准确率，可换用更大的中文模型（如 `vosk-model-cn-0.22`，约 1.3GB），下载后替换 `models/vosk` 目录即可，代码无需改动。

## 七、本地大模型接入（Ollama + RAG + 联网兜底）

系统采用「**知识库优先 → RAG 兜底 → 联网搜索兜底**」三级链路（竞赛版）：

| 优先级 | 链路 | 触发条件 | 标识 |
|--------|------|---------|------|
| ① | 知识库直答 | 问题命中 `qa_data.json` 关键词 | 显示知识库来源（如《云计算网络规划指导书》第3章） |
| ② | RAG 本地生成 | 知识库无直接命中，但检索到相关片段（相关度 ≥ 阈值） | 「由本地大模型基于实训知识库生成」 |
| ③ | **联网搜索兜底** | 知识库确实没有相关内容 | 「📎 参考来源（互联网检索）」+ 可点击来源链接 |

- **①** 直接返回知识库答案，不调用大模型（避免幻觉）
- **②** 检索本地知识库相关片段作为上下文，交给 Ollama 基于片段生成回答
- **③** 自动联网检索（必应RSS → 百度 → 必应 → 搜狗 → DuckDuckGo 五引擎择优回退），
  结果交 Ollama 总结；**Ollama 离线时直接罗列搜索结果**，保证始终有答案
- 学生说 **「联网搜一下 XXX」** 可跳过知识库，直接联网检索最新资料
- **范围外 / 越狱注入 → 一律拒绝，联网也不例外**（天气、游戏、八卦等不会触发联网）

### 联网兜底的安全设计

- **范围闸门前置**：只有通过实训范围白名单的问题才会联网，出站仅为技术查询关键词，不含学生身份信息
- **结果质量校验**：每条搜索结果做相关性评分，广告/降级页自动过滤，多引擎择优
- **强制溯源**：联网回答必须附来源链接，并提示「与课堂教材冲突时以教材为准」
- **一键开关**：环境变量 `ENABLE_WEB_SEARCH=0` 可恢复纯本地模式（用于考场等禁网环境）

### 安装组件（一般用不到：一键运行.bat 已内置安装逻辑）

`tools\一键安装.bat` 是**独立安装向导**，适合给已部分装好的机器补装组件（可选项逐项询问，必选项自动执行）：

```
[必选 1/2] 检查 Python 环境          ← 自动检测，缺了才装
[必选 2/2] 检查后端依赖              ← 自动安装，缺了才装
[可选 1/2] Ollama 大模型服务          ← 问你: [1=安装 / 2=跳过]
[可选 2/2] 下载大模型 [6 选 1]        ← 菜单: [1-6] 或 [0]跳过
是否立即启动云智? [1=启动 / 2=退出]
```

竞赛机批量部署用全自动模式（命令行执行）：`tools\一键安装.bat /auto`
→ 自动装齐 Python + 依赖 + Ollama + qwen2.5:3b 并启动。

> 也可单独使用以下 bat（适合已部分装好的机器补装）：

#### 单独安装 Ollama：双击 `tools\安装Ollama.bat`

- 自动从 ollama.com 下载安装包（约 200MB）
- 失败时回退到 PowerShell
- 安装后自动验证服务在线状态
- 仅需执行一次

#### 单独下载模型：双击 `tools\安装模型_xxx.bat`

每个 bat 只下载一个模型，学生根据自己电脑配置选一个：

| 脚本 | 模型 | 大小 | 适用场景 | 推荐配置 |
|------|------|------|---------|---------|
| `安装模型_qwen3b.bat` | qwen2.5:3b | 2.0 GB | 日常问答 轻量首选 | 4GB 内存 |
| `安装模型_qwen7b.bat` | qwen2.5:7b | 4.7 GB | 复杂推理 均衡首选 | 8GB 内存 / 6GB 显存 |

| `安装模型_glm4.bat` | glm4:9b | 5.5 GB | 工具调用强 | 8GB 内存 / 6GB 显存 |
| `安装模型_yi6b.bat` | yi:6b | 3.8 GB | 通用对话 中英均衡 | 6GB 内存 |

#### 完成后：双击根目录 `一键运行.bat` 启动云智

后端启动时会自动检测 Ollama 状态，在侧边栏显示「大模型在线·qwen2.5:3b · 联网兜底」或「知识库模式」。

### 手动安装（备用方案）

如 bat 脚本无法使用，按以下步骤手动操作：

1. 访问 [Ollama 官网](https://ollama.com/download) 下载 Windows 安装包并安装
2. 打开开始菜单的 Ollama 启动服务
3. 命令提示符执行：`ollama pull qwen2.5:3b`

### 配置（可选）

默认连接 `http://localhost:11434`、模型 `qwen2.5:3b`、联网兜底开启。如需修改，设置系统环境变量：

| 环境变量 | 说明 | 默认值 |
|---------|------|--------|
| `OLLAMA_HOST` | Ollama 服务地址 | `http://localhost:11434` |
| `OLLAMA_MODEL` | 使用的模型名 | `qwen2.5:3b` |
| `OLLAMA_TIMEOUT` | 请求超时（秒） | `120` |
| `RAG_MIN_SCORE` | 知识库相关度阈值（低于则联网兜底） | `4` |
| `ENABLE_WEB_SEARCH` | 是否启用联网搜索兜底（`0`=关闭） | `1` |
| `WEB_SEARCH_TIMEOUT` | 单个搜索引擎请求超时（秒） | `8` |
| `WEB_SEARCH_TOP_K` | 每次最多取用的搜索结果条数 | `5` |

> 若 Ollama 部署在另一台机器（如局域网服务器），把 `OLLAMA_HOST` 设为 `http://服务器IP:11434` 即可。
> **单文件版 `云智实训助手.html` 为纯离线静态页，不含联网搜索**；联网兜底需用根目录 `一键运行.bat` 运行完整版。

## 六、一键生成实训报告

位置：左侧导航「**报告生成**」页（或直接访问 `http://localhost:5000/#report`）。

### 使用方法

1. 填写六项内容：实训主题、**学习内容（必填）**、不会的东西、解决方法、教师指导、心得感受
2. 点击「**一键生成报告框架**」
3. 生成后点击「**复制报告**」，粘贴到 Word 里补充姓名班级后提交

### 报告框架结构（8 个章节）

一、实训基本信息 → 二、实训目的 → 三、实训环境 → 四、实训内容与操作步骤 → 五、遇到的问题与解决方法 → 六、教师指导记录 → 七、实训心得 → 八、总结与反思

### 智能引导说明

- 没填的部分不会留白，而是给出**琥珀色「怎么写」提示**（如姓名、班级、解决过程）
- 根据学习内容关键词**自动识别实训类型**（网络规划 / 云主机 / Web 服务 / 容器 / 数据库），提示应补充的环境信息
- 根据「遇到的问题」关键词给出**排查思路提示**（端口冲突 / 启动失败 / 连通性 / 权限），只给方向不代填命令
- 报告遵循**诚实边界**：系统只整理学生自己的记录并给写作引导，绝不编造命令与参数

### 安全机制

- 所有输入均做 HTML 转义（防注入攻击 / 页面破坏）
- 报告内容同样经过提示词注入检测，含越狱指令 → 「对不起，您的问题我无法回答」
- 单字段长度限制，防止恶意超长输入

> 单文件版 `云智实训助手.html` 内置纯前端版报告生成，双击即可使用；完整版（含智能问答）请用根目录 `一键运行.bat` 启动后端。

## 七、任务引导对话框

位置：左侧导航「**任务引导**」页（或直接访问 `http://localhost:5000/#task`）。

### 怎么用

1. 直接说任务名：**「云主机创建怎么做？」** 或 **「nginx 部署流程」**
2. 云智会给出任务总览 + 第一步操作（含操作指令、预期结果、原理提示）
3. 之后回复 **「下一步」/「上一步」/「第 N 步」/「验收标准」/「思考题」** 即可推进
4. **进度会记住**：同一台电脑上刷新页面后，回复「下一步」仍会接着上次的进度

### 询问别的会怎样？

任务引导页面的对话框与智能问答使用同一套安全策略：

- 问知识类问题（如"VPC 和子网是什么关系"）→ 照常从知识库回答
- 问无关内容 / 注入提示词 → **"对不起，您的问题我无法回答"**
- 知识库未收录 → "当前知识库暂未收录该问题，建议向现场指导教师求助"

| 任务 | 步骤数 | 来源 |

**添加新任务**：编辑 `knowledge/task_data.json`，复制一个任务的结构，改名称、关键词、步骤即可，无需改代码。

## 八、排错诊断：报错日志 / 截图诊断

位置：左侧导航「**排错诊断**」页（或直接访问 `http://localhost:5000/#diag`）。

### 使用方式（二选一或组合）

1. **截图诊断**：点「选择截图」上传报错截图 → 点「识别截图文字」→ 识别结果自动填入文本框 → 点「开始诊断」
2. **文字诊断**：直接把报错信息粘贴进文本框（或用自己的话描述故障现象）→ 点「开始诊断」

### 诊断输出（教育导向四段式）

**匹配特征 → 一、可能原因 → 二、排查命令（按顺序执行）→ 三、解决方案 → 四、原理讲解**

不只告诉学生"怎么办"，还讲清楚"为什么"，并标注参考来源（如《云计算排错手册》第1章）。

### 安全与边界

- 只处理实训相关内容：天气、游戏、写诗等无关内容 → **"对不起，您的问题我无法回答"**
- 提示词注入 → 同样拒绝
- 实训相关但知识库未收录的报错 → 给出通用排查思路（看状态→看日志→定位原因），不编造命令
- 截图仅保存在本机 `uploads/` 目录，绝不外发

### 截图识别（OCR）安装说明

**不安装也能用**：截图功能降级为"本地预览"，学生对照截图手动输入报错文字即可，文字诊断完全不受影响。

**想开启自动识别**（可选，一次性安装）：

1. 访问 https://github.com/UB-Mannheim/tesseract/wiki
2. 下载并安装 **Tesseract for Windows**（安装时勾选英文语言包即可，Linux 服务报错以英文为主）
3. 把安装目录（如 `C:\Program Files\Tesseract-OCR`）加入系统 PATH 环境变量
4. 重新运行 `一键运行.bat`，启动画面会显示「截图识别(OCR): 已启用」

> 如需识别中文报错截图，安装时额外勾选中文语言包（chi_sim）。
